一级 · 静止卡片
二级 · 悬停 / 浮起
三级 · 弹窗

亮色档的投影用**中性黑**，不用带色相的投影 —— 暖棕或藏青的投影会立刻让中性灰偏色。 层次靠"1px 描边 + 两级柔和投影"建立，不靠加深底色：那样会连同层次一起变浑。

暗色不是简单反相：用深暖棕黑替代纯黑、强调色提亮一档、阴影加深而不是变淡， 保证长时间盯着视频时页面边缘不刺眼。反色面（轻提示 / Tooltip）在暗色下要反过来变亮， 否则会糊进页面背景。
⚠️ 亮暗两档**故意不是同一套中性色**：亮色是纯中性灰（不偏黄也不偏蓝）， 暗色保留暖调。亮色档试过暖白底 + 珊瑚橙（整片发闷发脏，"层次"退化成色差极小的一片暖）、 冷蓝灰 + 学院藏青（干净，但和橙色强调像两套体系）—— 都不如中性灰。

弹窗 · 菜单 · 状态提示

浮层是最容易在暗色下露馅的地方：明度差不够就会糊成一片。 弹窗标题一律用功能级无衬线 —— 「删除 2 条会话」这种高频危险操作要一眼扫过， 衬线体的笔锋只会拖慢识别。

删除 2 条会话？

会连同对话记录与已渲染的视频一起删掉（成片、分段、增量缓存）， 不可撤销。

会话操作菜单

浮层与主界面的明度差、以及选中项的高亮方式。
